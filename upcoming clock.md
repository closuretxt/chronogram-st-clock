# The idea
I want this extension to create chronogram clocks for the current day for the user. It will also track around current time 12:00-12:15 and current date MM/DD/YYYY. It will also double down as a objective tracking extension keeping long term objectives.
It will use a separate model to track it, check for updates and completion.

The objective is even if the character is a simple singular character, the extension will allow for the story LLM to be aware that {{user}} has responsabilities and that {{char}} has as well. It would be cool that each character also could have separate chronograms the same way persist keeps different relationships using ids.

Keep similar settings from Persist and it also needs a popup window that customizeable and all.
